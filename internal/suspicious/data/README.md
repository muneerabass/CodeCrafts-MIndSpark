# Top-package lists (typosquat detection)

`internal/suspicious/typosquat.go` ports the typosquatting heuristic of
[Datadog guarddog](https://github.com/DataDog/guarddog) (v3.2.0, commit
`1f4a66c0`, Apache-2.0). The JSON files here are copied unmodified from
`guarddog/analyzer/metadata/resources/`. Format:
`{"downloaded_timestamp": <unix>, "packages": ["most-popular", ...]}`.

| File | Ecosystem | Upstream source | License |
|---|---|---|---|
| `top_npm_packages.json` | npm (8,000) | [npm-rank](https://github.com/tristan-f-r/npm-rank) (formerly LeoDog896/npm-rank) release `raw.json` | MIT, see below |
| `top_go_packages.json` | Go (2,921) | generated by guarddog (module references across top-starred repos) | Apache-2.0 (guarddog) |
| `top_rubygems_packages.json` | RubyGems (974) | [ecosyste.ms](https://packages.ecosyste.ms) critical gems API | CC BY-SA 4.0 (ecosyste.ms data). This file is shared under the same license. |

**PyPI is not embedded.** [hugovk/top-pypi-packages](https://github.com/hugovk/top-pypi-packages)
has no LICENSE file; only its Zenodo record has (auto-assigned) CC-BY-4.0
metadata, so redistribution is not clearly granted. The worker downloads
`https://hugovk.dev/top-pypi-packages/top-pypi-packages.min.json` on first use
into `$DEPGUARD_DATA_DIR` (default `<os temp dir>/depguard`) and refreshes it
every 30 days. If the download fails, the stale copy is used, or an empty
list, which turns off PyPI typosquat detection, retried hourly. Set
`DEPGUARD_TOP_PYPI_URL` to use a mirror, or to `off` for air-gapped installs. In
that case you can drop the file into the data dir yourself.
